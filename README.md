# Personal Portfolio Website - Agriya Yadav

A futuristic, engaging personal portfolio website showcasing your experience, projects, and skills in AI/ML and Full Stack Development.

## 🚀 Features

### Design
- **Futuristic Dark Theme** with glassmorphism effects
- **Particle Background System** with animated floating particles
- **Gradient Accents** (Cyan to Purple) throughout
- **Cursor Glow Effect** that follows mouse movement
- **Smooth Animations** on scroll and hover
- **Fully Responsive** design for all devices

### Sections
1. **Hero Section** - Eye-catching introduction with animated text
2. **About Section** - Biography, skills showcase, and animated statistics
3. **Experience Section** - Timeline view of work experience
4. **Projects Section** - Featured projects with hover effects
5. **Contact Section** - Multiple contact methods with icons

### Interactive Elements
- Smooth scroll navigation
- Active section highlighting in navbar
- Counter animations for statistics
- Hover effects on all interactive elements
- Text glitch effects
- Particle animations

## 🎨 Technology Stack

- **HTML5** - Semantic structure with SEO best practices
- **CSS3** - Modern styling with CSS variables, gradients, and animations
- **Vanilla JavaScript** - Interactive features and animations
- **Google Fonts** - Inter & Space Grotesk for premium typography

## 🎯 Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
    --accent-primary: #00f5ff;    /* Cyan accent */
    --accent-secondary: #7000ff;   /* Purple accent */
    --bg-primary: #0a0a0f;         /* Dark background */
}
```

### Content
Update your information in `index.html`:
- Personal details in Hero section
- Bio and skills in About section
- Work experience items
- Project cards
- Contact information
